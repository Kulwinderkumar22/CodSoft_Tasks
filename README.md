# CodSoft ML Internship – Tasks 1, 2, 3

Create one GitHub repo per task named `CODSOFT_TASK1`, `CODSOFT_TASK2`, `CODSOFT_TASK3`
(one folder each here). Install deps: `pip install -r requirements.txt`

| Task | Dataset (Kaggle) | Command |
|---|---|---|
| 1 Movie Genre | "Genre Classification Dataset IMDb" | `python movie_genre_classification.py --data_dir ./data` |
| 2 Fraud | "Credit Card Fraud Detection" (creditcard.csv) or fraudTrain/fraudTest | `python credit_card_fraud_detection.py --train creditcard.csv` |
| 3 Churn | "Churn Modelling" | `python customer_churn_prediction.py --data Churn_Modelling.csv` |
